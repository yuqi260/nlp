# 狼人杀玩家身份推断系统

本项目以旁观者视角，根据指定时点前的公开发言、投票和事件，预测玩家身份，并提供可回查的依据。已生成待核验的逐轮候选样本，并实现模型接口与评价脚本；**尚未进行真实模型调用或获得实验结果**。

## 目录

- `configs/`：游戏配置；实际规则以数据核验结果为准。
- `docs/data_formats.md`：公开事件、真实标签、预测快照、评分和输出的格式约定。
- `docs/audit/`：目标板子初步审计报告、逐局结构清单与统计；运行 `py -3 scripts/audit_makto.py` 可复现统计。
- `scripts/build_dataset.py`：生成公开信息快照、独立标签和按局划分；规则与限制参见 `docs/audit/预处理说明.md`。
- `docs/基线运行说明.md`：模型服务配置、少量验证样本调用及评价方法。
- `src/werewolf_nlp/`：项目代码，当前仅提供配置检查。
- `data/raw/`、`data/processed/`、`data/splits/`：原始数据、处理结果和按局划分清单，运行时创建，不纳入版本管理。
- `outputs/predictions/`、`outputs/metrics/`、`outputs/logs/`：预测、指标与运行日志，运行时创建。

## 检查初始配置

在本目录运行：

```powershell
py -3 scripts/check_config.py configs/nine_player.json
```

首版固定九人、五类角色；配置只定义人数与预测时点，不假定死亡是否公开身份、技能触发细节等尚未核实的规则。下一步先审计 MaKTO 数据，再根据数据补全规则。

## 信息边界

输入仅包含预测时点已经公开的信息；真实身份用于训练目标和离线评价，不进入输入。玩家声明不等于事实，未公开的夜间行动、私人思考、复盘与未来事件均不可进入输入。
