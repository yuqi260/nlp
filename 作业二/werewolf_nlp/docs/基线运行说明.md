# Qwen3.5-27B 直接预测基线

## 服务选择

优先使用阿里云百炼北京地域 `qwen3.5-27b`。官方模型页列出该型号和价格；开通前请在控制台确认地域、模型权限、价格和数据服务条款：[模型信息](https://help.aliyun.com/zh/model-studio/qwen3-5-27b)，[兼容接口](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-openai-chat-completions)。实际是否可用需通过账户验证。

2026-11-15 查看官方价格页，北京地域单次输入不超过 128K 时输入 0.6 元/百万 tokens、输出 4.8 元/百万 tokens，具体以控制台实际报价为准。官方文档列出该模型支持 LoRA 调优，账号可用性及费用需在提交时核验；现有通用推理 API 不会自动加载 LoRA。

## 使用

打开项目根目录的 `.env`，在 `WEREWOLF_API_KEY=` 后填入百炼 API Key。默认地址为北京地域，已填写。项目脚本启动时自动读取该文件；如果进程中已设置同名环境变量，则环境变量优先。`.env` 已加入 `.gitignore`，但它是本机明文文件，压缩或分享整个目录时请排除它。

也可以不用文件，在本目录的 PowerShell 中临时设置：

```powershell
$env:WEREWOLF_API_BASE_URL = 'https://dashscope.aliyuncs.com/compatible-mode/v1'
$env:WEREWOLF_API_KEY = [System.Net.NetworkCredential]::new('', (Read-Host '输入 API Key' -AsSecureString)).Password
```

先在百炼控制台确认地域及地址，以上是官方文档列出的北京地域兼容地址。完成后运行少量验证样本：

```powershell
py -3 scripts/run_baseline.py --model qwen3.5-27b --split validation --limit 3 --thinking off --retries 0 --output outputs/predictions/qwen3_5_27b_validation_pilot.jsonl
py -3 scripts/evaluate_baseline.py outputs/predictions/qwen3_5_27b_validation_pilot.jsonl --output outputs/metrics/qwen3_5_27b_validation_pilot.json
```

脚本不会覆盖已有输出；重复运行请选择新文件名。关闭当前 PowerShell 可结束会话环境变量，也可 `Remove-Item Env:WEREWOLF_API_KEY`。调用会将选定的公开对局文本发送到所选服务商，先确认数据使用条款。密钥不会写入输出，服务商可能记录请求；请勿将日志或原始输出当作匿名化数据。

## 规则提示对照

在配置好上述环境变量的 PowerShell 中，从项目目录运行。规则组使用与已有直接预测基线相同的验证快照和解码参数，系统提示追加预女猎规则、声明与公开事件的区别，以及票型和开枪的字段含义。

```powershell
py -3 scripts/run_baseline.py --split validation --limit 20 --model qwen3.5-27b --prompt-version rules_v1 --thinking off --temperature 0.6 --max-tokens 16384 --timeout 300 --output outputs/predictions/qwen3_5_27b_validation_rules_v1.jsonl
py -3 scripts/compare_validation.py outputs/predictions/qwen3_5_27b_validation_off_v1.jsonl outputs/predictions/qwen3_5_27b_validation_rules_v1.jsonl --output outputs/metrics/validation_rules_v1_comparison.md
```

比较脚本要求每组都覆盖完整验证集，报告成功快照的准确情况以及双方都成功的快照上的配对差值。公开身份掩码只排除实际开枪的玩家。

`--thinking off` 明确请求非思考模式；以服务商实际响应为准。所有模型版本、思考模式、提示词版本、温度和 token 上限应固定。API 默认一次最多请求 3 个快照，`--retries 0` 避免试运行额外重复计费；网络错误或重复请求仍可能产生费用。usage 由服务端提供，不等于实际账单。传输失败后无法得知服务端是否已经计费。

如只需检查选样和提示生成，不调用服务：

```powershell
py -3 scripts/run_baseline.py --model qwen3.5-27b --split validation --limit 3 --dry-run --output outputs/logs/dry_run.jsonl
```

也可设置其他 OpenAI Chat Completions 兼容端点与其实际模型 ID；除本机外必须使用 HTTPS。未验证的服务不应声称已使用 Qwen3.5-27B。提示词输入只含快照白名单字段和固定公开规则，不读取标签；身份匹配分和约束求解属于后续阶段。

## 评价与限制

输出包括模型原始回复、结构校验结果、角色数量是否合法、请求参数、耗时和服务端 usage。失败与不合规则的回复不会人工修成正确结果；结构合法但角色数量不符合配置的输出仍计入直接预测基线，并单独统计角色数量合法率。

离线评价报告成功率、成功样本的玩家准确率、各角色 F1、Macro-F1、整局快照完全正确率和分轮次准确率。**当前统计全部玩家，包含公开确认身份的玩家，仅用于初步调试；正式主指标须先构造并核验每轮已公开确认身份的标记。** 小样本仅用于流程检查，不能代表系统效果；测试集保持留出，不用于调整提示词。上游候选数据还需人工核验及近重复检查。
