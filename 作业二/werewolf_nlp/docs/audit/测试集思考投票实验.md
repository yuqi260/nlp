# 测试集三次思考投票实验

日期：2026-11-19。测试集共 14 局、23 个快照，之前的关闭思考直接基线已经查看；本次不属于全新盲测。每个快照独立调用 qwen3.5-27b：一次 direct_v1、两次 hypotheses_v1，均启用思考、temperature 0.6、max_tokens 16384。按玩家角色票数和角色配额整体分配，公开开枪者固定为猎人。同分按固定枚举顺序选首个。全部 69 次保存的调用成功且正常结束。

主口径只排除截止点之前实际开枪的猎人，尚未涵盖所有可能公开身份；同一对局的快照不是独立对局。

投票比旧直接基线高 4.93 个百分点；以逐局累计正确人数比较，14 局中 5 局上升、8 局持平、1 局下降。投票低于本次单次直接思考（64.53%），不足以支持投票相对单次思考有收益。验证集 87.50% 来自反复选择方案的小样本，不能当作测试表现。三次投票在 3/23 个快照出现同分最优。全部玩家口径投票为 131/207（63.29%）。

三组保存的请求合计输入 187257、输出 541205 token，累计请求时长 6401.11 秒；并行墙钟时间较短。按此前北京地域短输入价格粗估约 2.71 元，不包括中断中的 3 个请求、可能的重试或其他费用，实际账单以平台为准。成本和准确率须结合延迟判断，无法据此认为该方法适合实时部署。
